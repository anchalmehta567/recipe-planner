# Recipe Finder & Meal Planner

Monorepo containing two projects:

- **[`recipe-planner-app/`](recipe-planner-app/)** — the SvelteKit application (recipe discovery, details, favorites, weekly meal planner). See its [README](recipe-planner-app/README.md) for setup, assumptions, and links.
- **[`recipe-ui-components/`](recipe-ui-components/)** — the StencilJS web-component library published to npm as [`@anchalmehta/recipe-ui-components`](https://www.npmjs.com/package/@anchalmehta/recipe-ui-components) and consumed by the app above. See its [readme](recipe-ui-components/readme.md).

Start here: [recipe-planner-app/README.md](recipe-planner-app/README.md).
